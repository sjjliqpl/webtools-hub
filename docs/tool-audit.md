## 重点验证

- 数字记忆八档时长、正确/错误提交、结果焦点与设置取消。
- 六项新训练开始/输入/统计/结束；精确点击和瞄准训练命中与漏点；手机目标边界。
- 正则错误、灾难回溯超时和恢复；重复 URL 查询参数、文本增删、图片压缩上传与下载。
- Base64 Unicode/错误输入、空文本 SHA-256、JSON 格式化与压缩、计算器除零恢复。
- 倒计时暂停/恢复/结束，番茄钟工作转休息，笔记和待办存储。
- 表单弹窗显式关闭、收藏同步、双语搜索、主题保存、复制拒绝反馈、画板缩放坐标。

## 仍有边界

- 浏览器定时器不保证实验级曝光精度。
- 汇率为演示数据，色觉/健康工具不是诊断。
- 系统快捷键受浏览器和操作系统限制，触屏设备无法替代实体键盘训练。
- 本轮未覆盖所有浏览器及所有工具的全部输入组合。

## 发布前检查结果

- `npm run lint`、`npm test`（8 项）、`npm run build`、`git diff --check` 均通过。
- `npm audit`：0 个已知漏洞。
- Chromium：1440×1000 与 390×844，88 个路由共 176 次检查，无错误边界、页面异常或内容区横向溢出。
- 重点交互共 94 个断言通过，覆盖数字曝光八档、训练闭环、文件上传下载、定时器、存储、搜索、收藏、弹窗、Markdown 隔离和数值边界。
- 数字曝光实测为 74/119/226/327/518/1022/2017/3023 ms（设置 50/100/200/300/500/1000/2000/3000 ms）；含下一帧及调度延迟，不宣称实验级时序精度。
- 参考与实现：侧栏 220px、顶栏 56px、主色 #2563eb、背景 #f8f9fc、8px 面板圆角与独立滚动保持一致；工具内容采用卡片目录和专用训练区域。手机使用抽屉导航，深色使用同结构深色变量。
- Browser plugin not available；采用 Playwright CLI 验证。未覆盖真实触屏设备、Safari/Firefox、所有算法输入组合与环境音的主观音质。
