# 架构审查

现有纯前端架构适合本项目，无需新增后端。

| 用户动作 | 数据/能力 | 处理 |
|---|---|---|
| 分类、搜索、收藏 | 工具目录、localStorage | 共享应用状态，保留旧存储键 |
| 进入工具 | React lazy + 路由 | 统一工作台与错误边界，历史 URL 保持兼容 |
| 文本/编码预览 | 浏览器计算 | Unicode 校验，Markdown 使用无脚本沙盒 |
| 数字/鼠标/键盘训练 | performance.now、定时器、输入事件 | 处理清理、重置、误触、结果统计与响应式区域 |
| 文件处理 | File API + Canvas | 类型/大小限制，本地处理、下载结果 |
| 发布 | GitHub Actions + Pages | lint/test/build 后部署，验证 SPA 基础路径 |

已有问题：固定宽度训练区；秒级计数漂移与卸载清理缺失；Markdown 直接注入；部分进制接受非法字符；Unicode 二进制不符合 UTF-8；README/HTML 工具数量陈旧；深色模式与卡片嵌套不统一。
